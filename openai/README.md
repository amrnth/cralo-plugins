# Cralo for ChatGPT and Codex

Remote MCP plugin for ChatGPT Developer Mode, the ChatGPT/Codex plugin directory, and Codex.

- MCP URL: `https://mcp.cralo.ai/mcp`
- Auth: OAuth (PKCE). A scoped Cralo API key is the unattended/reviewer fallback.
- Billing: prepaid credits purchased at [cralo.ai](https://cralo.ai). There are no in-ChatGPT purchases.

## Developer Mode

1. Enable Developer Mode in ChatGPT.
2. Add a remote MCP server with URL `https://mcp.cralo.ai/mcp`.
3. Complete Cralo OAuth.

Public directory listing is a separate OpenAI portal submission. See [Submit plugins](https://developers.openai.com/plugins/deploy/submission).

## Privacy

Cralo processes tool inputs to fulfill catalog calls and bills prepaid credits. See [https://cralo.ai/privacy](https://cralo.ai/privacy), [https://cralo.ai/terms](https://cralo.ai/terms), and [https://cralo.ai/support](https://cralo.ai/support).
